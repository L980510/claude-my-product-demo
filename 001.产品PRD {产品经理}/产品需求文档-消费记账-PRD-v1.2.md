## 1. 产品概述

### 1.1 背景

很多人有「想管钱却坚持不下来」的痛点：记账软件要么功能过重，要么记录流程繁琐，导致记了几天就放弃。与此同时，还有两类人长期被主流记账工具忽略：

- **家庭 / 情侣**：想共同管理日常开销，但「共享记账」门槛高。
- **小微商户 / 个体户**：不需要完整的进销存或财务软件，只想用手机把每天的进账和开销记清楚、月底能看明白。

我们希望做一款**足够轻、打开就能记**的记账工具，同时用「场景化分类模板」兼顾个人与小微经营两类用户。

### 1.2 产品定位

一款面向个人与小微经营者的轻量记账工具，核心价值是：

> **让「记录今天这笔钱」这件事，快、轻、不费劲，并能随时看清「钱花哪儿了、进账多少」。**

第一版**不做**：完整进销存、发票税务、多人实时协作、投资理财等重功能（见第 9 章未来扩展）。

### 1.3 产品目标（第一版 / MVP）

- 用户从打开到记完一笔账，**平均耗时 ≤ 5 秒**。
- 核心路径（记一笔 → 看统计）无学习成本，首次使用无需教程。
- 手机浏览器内体验完整、流畅；数据本地可查、可导出。
- 通过**场景模板**同时覆盖「个人/家庭」与「小微/个体户」，一套产品两类用户可用。

### 1.4 产品形态与版本规划

| 版本 | 形态 | 范围 |
| --- | --- | --- |
| **V1（本次）** | Web 网页端（响应式，优先手机浏览器） | 单用户记账 + 统计 + 预算 + 导出 |
| V2 | Web 增强 + PWA | 可安装到桌面、离线使用 |
| V3 | 移动端 App / 小程序 | 原生体验、通知提醒、多人共享账本 |

> V1 是纯前端应用，优先保证手机浏览器（微信内置浏览器、Safari、Chrome 等）上的可用性。

### 1.5 目标用户

**年龄**：18 岁以上全年龄段（成年个人、家庭、经营者均可使用）。

| 用户类型 | 画像 | 核心诉求 | 优先级 |
| --- | --- | --- | --- |
| 个人 | 上班族/学生/自由职业者，每天记账 | 快速记录、分类清晰、月底看清支出 | 主 |
| 家庭 / 情侣 | 共同管理日常开销 | 记录共享支出、看清家庭收支 | 主 |
| 小微商户 / 个体户 | 小店、摊贩、自由职业接单者 | 记清每天进账与开销、简单统计 | 次（需兼顾） |

**使用设备**：手机为主（随时随地记），桌面浏览器为辅（查看统计）。

## 2. 用户使用场景

**场景一：随手记一笔（最高频）**
> 用户中午吃完饭，掏出手机，3 秒内记下「午餐 28 元」，然后立刻锁屏。

**场景二：月底复盘**
> 月底用户打开统计页，想知道「这个月餐饮花了多少、占比多少、是不是超了预算」。

**场景三：事后补记**
> 用户想起来昨天忘记了一笔打车费，补一条记录并选择昨天的日期。

**场景四：找一笔历史记录**
> 用户想确认「上周那笔 200 元的转账是什么」，通过搜索或筛选找到。

**场景五：情侣/家庭共同记开销（V1 内以单账本体现，共享留待 V3）**
> 情侣一起记账：各自记下今天的共同支出，月底一起看家庭总开销。
> *注：V1 仅支持单设备单账本，「多人共享账本」规划在 V3。*

**场景六：个体户记经营流水**
> 开早餐店的老板，每天关门后用手机记下「销售收入」「进货」「房租水电」，月底看进账和毛利。

## 3. 功能需求

### 3.0 功能总览（优先级）

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| P0 | 记一笔（收入/支出） | 产品核心，必须做到最快 |
| P0 | 场景化分类模板 | 个人/家庭版 与 经营/个体户版 |
| P0 | 账单列表 | 按时间倒序查看所有记录 |
| P0 | 分类管理 | 预设 + 自定义分类 |
| P0 | 统计报表 | 按分类/时间维度的汇总 |
| P1 | 月度预算 | 设置预算、超支提醒 |
| P1 | 搜索与筛选 | 快速定位历史记录 |
| P1 | 数据导出 | CSV 导出 |
| P2 | 多账本 | 区分日常/旅行/不同门店等 |
| P3 | 多人共享账本 | 家庭/情侣共同记账（V3） |
| P3 | 数据云同步 | 跨设备同步（V3） |

> **第一版范围：P0 全部 + P1 的月度预算。** P1 其余与 P2/P3 为迭代项。

---

### 3.1 记一笔（P0 · 核心功能）

**功能描述**：让用户在最短路径内完成一笔收入或支出的记录。

**流程**
1. 打开应用默认停留在「记一笔」输入页。
2. 选择「支出 / 收入」。
3. 输入金额（数字键盘，默认「支出」）。
4. 选择分类（默认记忆上一次使用的分类）。
5. 可选：备注、日期（默认今天）、账本（默认主账本）。
6. 点击「保存」。

**交互要求**
- 金额输入为第一焦点，打开即可直接输入数字。
- 分类用「九宫格图标 + 文字」，一键点选，不弹二级选择。
- 保存后**不跳转、不弹提示**，原地清空并给出轻量动效，方便连续记账。
- 支持「金额 + 备注」快捷语法（例如输入 `28 午餐` 自动拆分为金额 28、备注「午餐」），作为效率增强项。

**字段定义**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 类型 | 枚举 | 是 | 支出 / 收入，默认支出 |
| 金额 | 数字 | 是 | > 0，最多两位小数 |
| 分类 | 枚举 | 是 | 默认记忆上次分类 |
| 备注 | 文本 | 否 | 最长 50 字 |
| 日期 | 日期 | 是 | 默认今天，可回选 |
| 账本 | 枚举 | 是 | 默认主账本（P2 多账本上线前固定） |

**异常/边界**
- 金额为 0 或为空时，保存按钮置灰。
- 金额支持最高 9,999,999.99，超出时输入拦截。
- 无网络时也可正常记录（本地优先）。

---

### 3.2 场景化分类模板（P0 · 兼顾个人与经营的关键设计）

**功能描述**：首次使用时让用户选择「使用场景」，据此初始化不同的分类体系，让个人和个体户各自拿到「开箱即用」的分类，而不是共用一套不贴合的默认分类。

**两种模板**

| 模板 | 支出预设 | 收入预设 |
| --- | --- | --- |
| 个人 / 家庭 | 餐饮、交通、购物、居住、娱乐、医疗、教育、人情、其他 | 工资、奖金、理财、红包、其他 |
| 经营 / 个体户 | 进货采购、房租、水电、人工、物流、耗材、税费、其他 | 销售收入、服务收入、其他 |

**要求**
- 首次进入引导选择场景（个人 / 经营），之后可随时在「分类管理」中切换或混用。
- 允许用户在任意模板基础上自由增删改分类（见 3.4）。

---

### 3.3 账单列表（P0）

**功能描述**：以时间倒序展示所有流水记录，可按月查看。

- 默认按月分组展示，顶部显示当月「支出合计 / 收入合计 / 结余」。
- 每条记录展示：分类图标、分类名、备注（如有）、金额（支出为负、收入为正）。
- 支持左滑或长按删除 / 编辑。
- 支持按天分组折叠，快速定位某一天。

---

### 3.4 分类管理（P0）

**功能描述**：预设常用分类，支持用户自定义。

**要求**
- 用户可新增、重命名、删除分类。
- 删除有流水的分类时，需引导用户将原有流水「归类到其他」或「批量转移」，不可硬删导致数据丢失。
- 每个分类可自定义图标与颜色（MVP 至少支持颜色）。

---

### 3.5 统计报表（P0）

**功能描述**：让用户直观了解「钱花在了哪、进了多少」。

**报表维度**
1. **分类占比**：饼图 / 环形图，展示各支出分类金额与占比。
2. **趋势**：折线图，展示日 / 周 / 月支出（可切换收入）变化趋势。
3. **收支汇总**：本月收入、支出、结余三张大卡片。
4. **毛利概览**（经营模板下）：收入 − 支出 = 结余，突出「进账 / 开销 / 结余」。

**要求**
- 支持时间范围切换：本周 / 本月 / 上月 / 自定义区间。
- 点击饼图某分类，可下钻查看该分类的明细流水。
- 数据可视化遵循统一设计规范（配色、图例、深浅色适配，见第 5 章视觉设计规范）。

---

### 3.6 月度预算（P1）

**功能描述**：用户设置每月支出预算，系统进行进度提示。

- 设置每月总预算（可选：按分类设置预算，MVP 只做总预算）。
- 统计页显示「本月已花 / 预算 / 剩余」，以进度条展示。
- 剩余预算不足时（如低于 20%）给出温和提醒，超支时红字提示。

---

### 3.7 搜索与筛选（P1）

- 支持按关键字搜索备注。
- 支持按「分类 / 类型 / 金额区间 / 日期」组合筛选。

---

### 3.8 数据导出（P1）

- 一键导出当前筛选结果或全部数据为 CSV。
- 导出字段与账单字段一致，方便用户在 Excel 中二次处理。

## 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 形态 | 响应式 Web，优先手机浏览器（Safari / Chrome / 微信内置浏览器） |
| 性能 | 记账保存响应 ≤ 300ms；列表滚动流畅，千条数据不卡顿 |
| 可用性 | 手机单手可完成记账；字体与点击区域符合触控规范 |
| 数据安全 | 本地优先存储（浏览器 IndexedDB）；如引入云端，需加密传输与存储 |
| 兼容性 | iOS / Android 主流浏览器；桌面浏览器兼容性兜底 |
| 隐私 | 不强制注册登录即可使用；不采集与记账无关的个人信息 |
| 可扩展性 | 数据模型预留「账本」「标签」「成员」扩展字段，为 P2/P3 做准备 |

## 5. 视觉设计规范（配色方案）

### 5.1 设计基调

- 关键词：**粉嫩、可爱、柔和、圆润、治愈**。
- 整体给人「轻松记账、无压力」的观感，弱化传统财务软件的冷硬感。
- 个人/家庭与经营/个体户两套模板共用同一套配色，通过图标与信息层级区分场景，保持品牌统一。

### 5.2 配色方案

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主色 · 樱花粉 | `#FF9EB5` | 主按钮、底部导航选中态、关键强调 |
| 主色 · 深粉 | `#F4719A` | 按钮按下态、重点数据、进度条 |
| 辅助 · 浅粉 | `#FFE4EC` | 卡片背景、分类选中底色、标签 |
| 辅助 · 奶油白 | `#FFF7F9` | 页面主背景 |
| 点缀 · 蜜桃橙 | `#FFC9A9` | 暖色点缀、金额强调 |
| 点缀 · 薄荷绿 | `#A8E6CF` | 收入金额、正向数据 |
| 点缀 · 浅紫 | `#D9C7F0` | 分类图标点缀色 |
| 文字 · 主 | `#5A4A4A` | 标题、金额主文字（暖棕灰，不用纯黑） |
| 文字 · 次 | `#A89090` | 辅助说明、时间戳、占位文案 |
| 警示 · 珊瑚红 | `#FF7B8A` | 超支提醒、删除等警示场景 |

### 5.3 使用规范

- **主色**（樱花粉 / 深粉）：用于主操作按钮、底部导航选中态、进度条、选中分类背景。
- **浅粉 / 奶油白**：用于大面积背景与卡片底色，避免高饱和粉色造成视觉疲劳。
- **金额语义**：支出金额用暖棕灰 / 深粉；收入金额用薄荷绿，延续「支出/收入」的记账直觉。
- **分类图标**：九宫格图标使用「樱花粉 + 浅紫 + 蜜桃橙 + 薄荷绿」的低饱和马卡龙色系轮换，可爱且柔和。
- **警示场景**：超支、删除等用珊瑚红，提醒明确但不破坏整体柔和感。

### 5.4 视觉风格

- **圆角**：卡片大圆角（12–16px），按钮为胶囊形圆角。
- **图标**：圆润卡通 / 手绘风图标，不使用生硬的线性几何图标。
- **字体**：圆润无衬线（苹方 / 系统圆体等），数字金额可稍加粗。
- **动效**：保存成功用轻快弹跳 / 爱心微动效，贴合可爱基调。
- **深浅色**：第一版优先保证浅色（粉嫩）体验，深色模式作为后续迭代项。

## 6. 数据需求

### 6.1 核心数据模型（最小可行）

```
Record（账单流水）
  - id          唯一标识
  - type        支出 | 收入
  - amount      金额（分，整数存储避免浮点误差）
  - categoryId  分类 ID
  - note        备注
  - date        记账日期（YYYY-MM-DD）
  - createdAt   创建时间戳
  - bookId      账本 ID（预留，默认主账本）

Category（分类）
  - id
  - name        名称
  - type        所属类型（支出/收入）
  - icon        图标标识
  - color       颜色
  - sort        排序权重
  - isSystem    是否预设
  - scene       所属场景模板（personal / business）

Book（账本，预留）
  - id
  - name        账本名称
  - type        个人/家庭/经营

Budget（预算）
  - id
  - month       月份（YYYY-MM）
  - amount      预算金额
```

> 金额统一以「分」为整数单位存储，展示时再格式化为元，避免浮点数精度问题。
> V1 数据存于浏览器本地；后续 V3 云同步时需引入账号体系与数据迁移方案。

## 7. 页面结构（信息架构）

```
首页（记一笔）
  ├─ 类型切换（支出/收入）
  ├─ 金额输入
  ├─ 分类九宫格
  ├─ 备注 / 日期
  └─ 保存

账单（列表页）
  └─ 记录卡片 → 详情/编辑/删除

统计（报表页）
  ├─ 收支汇总卡片（经营模板含毛利）
  ├─ 分类占比图
  └─ 趋势图

我的（设置页）
  ├─ 场景与分类管理
  ├─ 预算设置
  ├─ 数据导出
  └─ 关于
```

底部导航：**记一笔 / 账单 / 统计 / 我的**（记一笔放在最中间或最左侧，便于拇指触达）。

## 10. 成功指标（上线后跟踪）

- **记账完成率**：进入记一笔页到保存成功的转化率（目标 ≥ 90%）。
- **单笔记账耗时**：目标均值 ≤ 5 秒。
- **次日留存 / 7 日留存**：衡量「能否坚持记下去」。
- **月活跃记账天数**：衡量使用粘性。
