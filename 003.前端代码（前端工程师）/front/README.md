# 消费记账 · V1（Web 网页端）

依据 [001.产品PRD {产品经理}/产品需求文档-消费记账-PRD-v1.3.md](../../001.产品PRD%20{产品经理}/产品需求文档-消费记账-PRD-v1.3.md) 开发的第一版。纯前端、无构建、本地存储，手机浏览器优先。

## 如何运行

任选其一：

1. **直接打开**：双击 `index.html`（浏览器本地打开即可，无需服务器）。
2. **本地服务器**（推荐，行为更接近线上）：
   ```bash
   cd app
   python -m http.server 8080
   ```
   然后手机与电脑同一局域网，访问 `http://<电脑IP>:8080` 即可在手机上体验。

> 手机上体验建议用方式 2，并用手机浏览器访问电脑的局域网 IP。

## 已实现功能（V1 = P0 全部 + 月度预算）

- **登录 / 注册（演示）**：用户名 + 密码的账号体系，纯前端模拟、无真实后端；不同账号数据互相隔离，可退出登录 —— 用于演示 v1.3 流程
- **记一笔**：支出/收入切换、金额输入（唤起数字键盘）、分类九宫格、备注、日期、保存；支持「28 午餐」快捷语法；保存后原地清空 + 弹跳动效
- **场景化分类模板**：首次进入选择「个人/家庭」或「经营/个体户」，初始化对应分类；之后可随时切换合并
- **账单列表**：按月查看、当月支出/收入/结余汇总、按天分组、点击编辑、删除
- **分类管理**：新增 / 重命名 / 删除（删除时流水自动转移到「其他」）、自定义图标与颜色
- **统计报表**：收支汇总卡片、支出分类占比环形图、收支趋势折线图、本周/本月/上月切换、明细表格兜底
- **月度预算**：设置预算、进度条、剩余不足 20% 与超支提醒
- **数据导出**：一键导出 CSV（带 BOM，Excel 可直接打开）

## 技术方案与对 PRD 的取舍

| 项 | 决策 | 说明 |
| --- | --- | --- |
| 技术栈 | 纯 HTML/CSS/JS，无构建 | V1 目标「打开就能用」，零依赖、离线可用 |
| 数据存储 | localStorage | PRD 写的是 IndexedDB；V1 用 localStorage 简化（单用户、量级小足够），后续迁 IndexedDB；账号登录为演示，数据按账号 ID 前缀隔离 |
| 金额 | 以「分」整数存储 | 与 PRD 一致，避免浮点误差 |
| 图标 | Emoji | 贴合「圆润卡通」且零依赖；可后续换手绘 SVG 图标 |
| 图表 | 手写 SVG | 不依赖 CDN；环形图 + 折线图 |
| 图表配色 | 糖果色（较饱和） | PRD 的纯马卡龙色过浅、图表区分度不足；改用经 `dataviz` 校验通过的饱和糖果色，UI 主体仍是 PRD 粉嫩色 |
